THE PROBLEM I SET OUT TO FIX

Tables that survive the journey.

Most free converters (including Calibre's ebook-convert and many online tools) destroy or completely mangle tables from Word and especially PDF. The result is unreadable garbage on your Kobo.

KoboForge is deliberately conservative: it keeps real semantic tables wherever possible, uses clean reflowable XHTML, and applies Kobo-specific typography and spacing. The DOCX path is especially robust because tables in .docx are explicit and well-structured.

For the most complex or scanned PDFs, the Desktop Companion (Python + pdfplumber) gives even higher fidelity.

FOR THE HARDEST PDFs

Desktop Companion (Python)

The web version is excellent for DOCX and clean PDFs. For dense scientific tables, financial reports, or scanned documents, use the local Python tool that leverages pdfplumber for state-of-the-art table extraction and reconstruction.

Quick start (no install fuss) 
pip install pdfplumber python-docx ebooklib pillow typer
# Then download koboforge-companion.py (or copy the script from the repo)
python koboforge-companion.py report.pdf --preset libra --output report.epub
The companion is included in the site repository. It produces the cleanest possible EPUBs when table fidelity is non-negotiable. View companion source →
