KoboForge

Private EPUB tooling for Kobo readers.

KoboForge is a practical conversion workflow for readers who want better EPUB output from PDFs and DOCX files without uploading private documents. The current public surface is this project page plus a local Python companion.

Local-first

Run conversion on your own machine for private documents and drafts.

Built for hard cases

Designed around tables, scanned pages, wide layouts, and messy source files that simple converters often mishandle.

Kobo-aware

Aims for readable EPUB output with metadata and layout choices suitable for Kobo devices.

Use the companion tool

The repository includes the active companion script under `tools/`. Run it locally from the site root. 

python3 tools/koboforge-companion.py input.pdf --output output.epub
