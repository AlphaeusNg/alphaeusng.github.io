# Pages

This folder contains secondary deployable pages for the portfolio.

- `conviction.html`: TSLA-versus-SPY benchmark comparison page.
- `kobo-forge.html`: KoboForge project overview.
- `seeking-biblical-truth/`: public graph viewer generated from the separate `Seeking-Biblical-Truth` vault repository.
- `data/tsla-vs-spy.json`: static monthly data source for `conviction.html`.

Root-level files such as `conviction.html`, `kobo-forge.html`, and `seeking-biblical-truth/index.html` are compatibility redirects so older links keep working.
