Benchmark Comparison

Actual TSLA position vs SPY benchmark

This page compares the value of a real TSLA trade path with a hypothetical SPY position funded by the same dated cash flows, then shows the dollar gap between them. SPY is used here as the practical S&P 500 proxy.

How To Read This

  • TSLA uses the actual anonymized buy and sell path.
  • SPY is a hypothetical S&P 500 proxy using the same signed cash flows.
  • Values are marked at monthly close, not intraday execution.
  • This is a methodology page, not investment advice.

Chart

Value path, cash flows, and delta

The default view compares ending value paths. Alternate views show the monthly capital schedule and the value gap between the TSLA path and the benchmark path.

Methodology

Each calendar month aggregates the anonymized TSLA trade flow. The benchmark then applies the same signed dollar flow to SPY at that month's close: positive flow creates SPY units and negative flow redeems SPY units. The published chart values both paths at monthly close.

Assumptions

TSLA and SPY both use split-adjusted monthly closes. Benchmark funding uses gross trade notional rather than broker-fee-perfect cash accounting because the pasted fee fields are not consistent across the full export.

Limitations

This is a monthly-close approximation, not a tax lot system. It does not model dividends separately, taxes, or exact benchmark fills on each trade date. It is a value-comparison tool, not evidence that one approach is always superior.

Source Data

The public page is driven by a static JSON export generated from an owner-anonymized TSLA trade ledger and public monthly price history for TSLA and SPY. View the published dataset.
